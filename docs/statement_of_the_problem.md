Many organizations deploy cloud storage resources without implementing proper security controls. Misconfigured bucket permissions, publicly accessible storage, inadequate encryption, disabled logging and over-privileged accounts expose sensitive information to unauthorized access.
According to the 2024 Cloud Security Alliance report, configuration weaknesses and IAM-related issues remain among the highest-ranking cloud security threats. Furthermore, large-scale cloud risk assessments published in 2024 identified exposed cloud storage assets as a significant area of concern across cloud environments. (Cloud Security Alliance Releases Top Threats to Cloud | CSA).
These issues create substantial operational, financial and reputational risks for organization

The aim of this study is to review cloud bucket configurations and evaluate security controls used to protect cloud storage resources from unauthorized access, data leakage and security breaches.

The study aims to:
1.	Examine cloud bucket architecture and storage configurations.
2.	Identify common bucket security misconfigurations
3.	Assess access control mechanism used in cloud storage
4.	Evaluate encryption and monitoring controls
5.	Analyze recent cloud security trends and threats
6.	Recommend best practices for bucket security and compliance.
