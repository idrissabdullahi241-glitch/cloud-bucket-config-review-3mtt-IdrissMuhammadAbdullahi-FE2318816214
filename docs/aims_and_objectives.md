The aim of this study is to review cloud bucket configurations and evaluate security controls used to protect cloud storage resources from unauthorized access, data leakage and security breaches.

The study aims to:
1.	Examine cloud bucket architecture and storage configurations.
2.	Identify common bucket security misconfigurations
3.	Assess access control mechanism used in cloud storage
4.	Evaluate encryption and monitoring controls
5.	Analyze recent cloud security trends and threats
6.	Recommend best practices for bucket security and compliance.
